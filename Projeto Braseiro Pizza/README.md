# Braseiro Pizzas — Cardápio Online

Landing page de cardápio para pizzaria, feita para receber tráfego de anúncio (ads). Mobile-first, carregamento rápido, pedido direto por WhatsApp em cada pizza.

## Estrutura

```
.
├── index.html   # página única (HTML + CSS embutido)
└── README.md
```

## Antes de publicar

- [ ] Trocar o número de WhatsApp de exemplo (`5500000000000`) pelo número real, em **todos** os botões "Pedir" (um por pizza) e no botão do rodapé
- [ ] Conferir/ajustar nome, sabores, descrições e preços
- [ ] Confirmar horário de funcionamento no rodapé
- [ ] (Opcional) trocar/ajustar nome e paleta de cores, se quiser algo diferente do sugerido

## Como publicar (GitHub Pages)

1. Suba este conteúdo para um repositório no GitHub
2. Vá em **Settings → Pages**
3. Em "Source", selecione a branch principal (ex: `main`) e a pasta raiz (`/`)
4. Salve — o GitHub vai gerar uma URL pública (ex: `https://seu-usuario.github.io/braseiro-pizzas/`)
5. Use essa URL no link do anúncio

## Como rodar localmente

Basta abrir o arquivo `index.html` no navegador — não depende de servidor, build ou instalação.
